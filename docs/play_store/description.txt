SHORT DESCRIPTION (66/80 characters)
------------------------------------------------
Private AI that runs entirely on your phone. No cloud, no account.

FULL DESCRIPTION (3457/4000 characters)
------------------------------------------------
InstaLLM runs AI models on your own device. Nothing you type is sent anywhere to get a reply: the model runs on your phone, its file stays in the app's private storage, and everything keeps working with the network off once a model is installed. No account, no sign-in, no subscription.

CHAT
• Streaming replies you can stop at any moment
• Create, rename, search, pin and delete conversations
• Switch models mid-conversation without losing the history
• Every reply records which model wrote it, with speed and token stats
• Regenerate a reply, or edit your prompt and send it again
• Context readout above the composer, with a note when older turns are trimmed
• Markdown and code blocks with one-tap copy
• Personas: reusable system prompts chosen per conversation
• Memory: facts you choose to remember, in a chat or a whole workspace
• Read aloud and Regenerate on every reply

MODELS
• Import a GGUF model from storage, paste a direct link, or download from Hugging Face
• Built-in catalog: Qwen, Qwen Coder, Llama 3.2, SmolLM2, Gemma, Phi, TinyLlama, LFM2, MiniCPM3
• Resumable downloads with pause, progress and a notification when one finishes
• Each entry shows size, quantisation and vision support, plus a fit estimate for this device's memory
• Search and filter by parameter size, with the model in use marked in the list
• One row per file, unfolded in place for architecture, context window and chat template

VOICE AND VISION
• Voice mode with its own dock: dictate, hear replies read aloud, pick the voice
• Offline speech-to-text with Whisper models, or the device's own recogniser
• Attach a photo to a vision model, or reuse an image already in the chat
• Images are downscaled and re-encoded without EXIF or GPS before they reach the model

KNOWLEDGE ON THE DEVICE
• Attach files to a chat, or index documents into knowledge collections
• Chunking, weights, reranking and a retrieval preview you can tune
• Read ICS calendars and mbox inboxes locally, with no account and no sync
• Scheduled tasks and reminders that fire offline

WORKSPACES, BOTS AND ROOMS
• Workspaces link bots, chats and skills to one project
• Bots with their own instructions, model, skills and workspaces, including Researcher, Planner, Coder and Tester
• Rooms for group conversations between bots, routed by @mention
• Skills: reusable procedures a bot loads when it needs them
• MCP servers, so a bot can call external tools under per-tool permissions
• Hooks: rules that refuse a tool call or ask you first
• Hand text, a link, an image or a PDF in from another app; it waits in the composer until you press send
• Set InstaLLM as the default assistant, or ask about what is on screen from the assistant gesture

CONTROL
• Inference profiles bundle context size, threads, GPU offload and sampling per model
• A context budget, so long chats still fit the model you are running
• Benchmark: run one prompt across installed models and compare measured speed on this hardware
• Light, dark or system appearance with accent colour and contrast options
• Image size and metadata controls for attachments

YOUR DATA
• No account, no analytics, no advertising, no telemetry
• Back up chats, personas, profiles, settings and benchmarks to one file, and restore it
• Delete chats, models and attachments from inside the app
• Network use stays off until you enable it per workspace; the only other request is a download you start
• Open source under the GNU GPL v3
