language; the count in the heading is checked against it.

What's new in 1.7.0

• InstaLLM now asks Google Play for a newer build on launch and offers it in one tap, or stays quiet until you say so
• A failed Hugging Face repository lookup names its cause (rate limit, timeout, network)
• Resumed model downloads finish without corrupting the file, and progress stops at 100%
• A model whose file has gone missing says so instead of looking installed
• Chats save as PDF, Markdown, text or JSON
