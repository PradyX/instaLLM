InstaLLM · Google Play release notes
====================================
Paste the block below into Play Console → Testing → Internal testing (or
Production) → "What's new in this release". Play's limit is 500 characters per
language; the count in the heading is checked against it.

RELEASE NOTES (versionName 1.6.2 · versionCode 3 · 425/500 characters)
--------------------------------------------------
What's new in 1.6.2

• Model downloads now finish: a resumed download no longer corrupts the file, and the progress bar stops at 100%
• If a model's file has gone missing, the app says so instead of showing a broken install
• Imported models that bring their own prompt format now answer properly instead of garbled text
• Save a chat as PDF, Markdown, text or JSON — on Android it lands in Downloads and opens from the notice
